🌸 Iris Flower Classification Model

A simple machine learning project to classify Iris flower species using Decision Tree Classifier and Principal Component Analysis (PCA) for visualization.
This project is created as part of my M.Sc. in Medical Bioregulators and Bioinformatics (3rd Semester) coursework in Machine Learning and Bioinformatics.

📘 Overview

The Iris dataset is one of the most famous datasets in pattern recognition.
It contains measurements of iris flowers from three species — Setosa, Versicolor, and Virginica.

This project demonstrates:

Loading and exploring a dataset using Pandas

Applying PCA for dimensionality reduction

Building a Decision Tree Classifier

Evaluating model performance

Visualizing the Decision Tree and PCA projection

🧠 Concepts Used

Supervised Learning

Decision Tree Algorithm

PCA (Principal Component Analysis)

Model Evaluation Metrics (Accuracy, Confusion Matrix, Classification Report)

Data Visualization using Matplotlib and Seaborn
